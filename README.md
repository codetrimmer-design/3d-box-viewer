# 3D Box Viewer

Interactive 3D visualization of a box model (3mm × 3mm × 6mm) built with Three.js.

**[View Live](https://codetrimmer-design.github.io/3d-box-viewer/box_viewer.html)**

## Files

- `box_viewer.html` - Browser-based 3D viewer with orbit controls
- `box_3x3x6.step` - STEP CAD file of the box model

## Features

- Mouse orbit controls (rotate, pan, zoom)
- Wireframe toggle
- Edge display toggle
- Dimension labels (X: 3mm, Y: 6mm, Z: 3mm)
- Grid and axes helpers

## Usage

Open `box_viewer.html` in any modern browser. Controls:

| Action | Input |
|--------|-------|
| Rotate | Click + drag |
| Zoom | Scroll wheel |
| Pan | Right-click + drag |
